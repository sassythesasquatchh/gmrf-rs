# Upstream lineage

This repository was created as a curated import of the supported `gmrf-core`
crate from:

- repository: <https://github.com/sassythesasquatchh/gmrf>
- imported commit: `ddfc9f79e0ba74f0452489f4fcf17fbc564ab2e4`
- imported path: `crates/gmrf-core`

That earlier repository recorded its divergence from Tim Weiland's original
work at commit `6cfba1e6ab8a71b49eabd5a0545e7eb72eae940a`.

The fresh Git history is intended to give the supported Rust crate a clear
release boundary. It does not replace or obscure the earlier authorship:

- original author and copyright holder: Tim Weiland;
- subsequent Rust integration and GMRF work: Patrick Dowd and contributors;
- license: MIT; see [LICENSE](LICENSE).

The old repository remains the authoritative history for development before
this curated import. This repository's initial commit is an import, not a claim
that its contents were authored from scratch at that commit.
